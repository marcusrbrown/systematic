Systematic ships a self-contained Claude Code plugin bundle, generated from the same skills and agents that power the OpenCode and Pi integrations. The bundle lives at `claude-code/` in the package and targets Claude Desktop's embedded Claude Code (the Code tab) and Cowork.

## Install

The plugin is distributed through the Claude Code plugin marketplace flow. In Claude Desktop:

1. Open **Cowork → Customize → Plugins** (or the equivalent plugin management surface in the Code tab).
2. Install the `systematic` plugin.
3. Enable it for the project or workspace you want it active in.

You can also install from the command line using Claude Code's plugin install flow, pointing at the marketplace entry or a local path to the `claude-code/` bundle for testing.

Installing the plugin does not require or touch an existing OpenCode or Pi setup in the same project — the three integrations are independent.

## What you get

Once installed and enabled, the plugin registers:

- **Bundled skills as native Claude Code skills** — every skill under `claude-code/skills/` ships as a `SKILL.md` (with subfiles) copied verbatim from the source skill directory, so Claude Code's own Skill tool discovers and invokes them the same way it would any other skill.
- **Bundled agent personas as native subagents** — persona files are flattened into `claude-code/agents/`, one Markdown file per agent, and dispatched by name in a prompt (for example, "Use the systematic-implementer subagent to implement the auth module").
- **Behavioral enforcement via a plugin output style** — `claude-code/output-styles/systematic.md` composes the using-systematic discipline (invoke skills before responding, plan before multi-step changes) with the Claude Code capability profile and a full skill catalog. Output styles with `force-for-plugin: true` modify the system prompt directly and auto-apply as soon as the plugin is enabled — this is the mechanism that makes enforcement install-alone rather than something you have to separately configure.
- **Declarative session state via a `SessionStart` hook** — `claude-code/hooks/hooks.json` runs a static command that reports the active Systematic version and the full skill/agent catalog into session context. This hook carries state only; it does not attempt to inject behavioral instructions, because imperative hook content is treated as prompt injection and refused.

## The layered model

Systematic's Claude Code integration is deliberately layered rather than relying on one mechanism to do everything:

| Layer | Mechanism | Role |
|---|---|---|
| Enforcement | Plugin output style (`force-for-plugin: true`) | Authoritative, install-alone behavioral discipline |
| State | `SessionStart` hook | Declarative session facts (version, catalog) only |
| Workflow | Native skills | Skill content and instructions, discovered natively |
| Agents | Native subagents | Persona dispatch by name |

## Honest capability boundary

Output-style enforcement is real and applies automatically on install, but it operates at the system-prompt level, the same layer as any other instruction the model receives — it is strong guidance, not a hard gate the model cannot violate. Treat it the way you would treat any other system-prompt-level policy: reliable in practice, not cryptographically enforced.

Coverage also differs by surface. Plugin-bundled hooks fire app-wide, including in Cowork. A project-local `.claude/settings.json` hook, by contrast, fires in the Code tab but not in Cowork — if you need state or enforcement to reach Cowork sessions, it has to come through the plugin, not a project-local hook.

Systematic ships no `systematic_skill` tool on Claude Code, unlike its OpenCode and Pi adapters. Skill invocation goes entirely through Claude Code's own native Skill tool and `SKILL.md` discovery — there is no Systematic-specific resolution layer to reason about on this harness.

## Uninstall

Disable or remove the plugin from Cowork → Customize → Plugins (or the equivalent Code tab surface). No project files are modified by installation, so there is nothing else to revert.
