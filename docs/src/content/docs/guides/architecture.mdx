Systematic is designed as a lightweight yet powerful extension for OpenCode. It leverages native plugin hooks to inject structured workflows and specialized agents into your development environment.

## Overview

The plugin is divided into two main parts:
1.  **TypeScript Source (`src/`):** The core logic that handles plugin registration, asset discovery, config validation, and model availability resolution.
2.  **Bundled Assets (`skills/` and `agents/`):** Structured engineering workflows and specialized agent definitions that are automatically discovered and registered by the plugin.

### 1. `config` Hook
The `config` hook is responsible for discovery and merging. It recursively walks the bundled asset directories (`skills/` and `agents/`) and merges their definitions into your active OpenCode configuration. This ensures that agents like `@architecture-strategist` are available without manual setup.

### 2. `tool` Hook
The plugin registers a custom tool called `systematic_skill`. This tool is used by the AI to load the full content of bundled skills on demand. While OpenCode has a native `skill` tool, `systematic_skill` provides optimized access to the plugin's bundled content.

`systematic_skill` takes an optional `arguments` string. If the skill text contains `$ARGUMENTS`, that gets replaced with the whole string. If it contains `$1`, `$2`, and so on, those get replaced with positional values (quoted text counts as one value, and the highest-numbered placeholder takes the rest of the string) — the same rules OpenCode uses for its own slash commands. If the skill has none of these placeholders, the argument text is appended after the skill body instead. Leaving `arguments` out entirely leaves any placeholders in the skill text untouched. This is text substitution only — it never executes anything.

### 3. `tool.execute.after` Hook
OpenCode truncates plugin tool output at 2,000 lines or 50 KB by default. This hook restores the full skill text after that cut so large skills still arrive complete. If your own config sets `tool_output.max_lines` or `tool_output.max_bytes`, Systematic honors your limit and skips the restore.

### 4. `messages.transform` Hook
OpenCode's opt-in `compaction.prune` setting replaces older tool results with a placeholder, and it exempts only its own built-in `skill` tool. This hook clears that placeholder flag on completed `systematic_skill` results in the request being assembled, so the model receives the stored body again. What this covers:
- With `compaction.prune` on, a loaded skill's body survives pruning and the retained tail, but not full-session summarization.
- The edit applies only to the request. Storage still marks the result as pruned.
- Prune still counts the body toward its protect window, which it skips for the native `skill` tool.
- The full-session summarizer sees a 2,000-character slice of the body.
- A host that predates the hook never calls it, and keeps the placeholder.

### 5. `system.transform` Hook
This hook allows Systematic to inject a "bootstrap" instruction into the AI's system prompt at the start of every conversation. This instruction (from the `using-systematic` skill) teaches the AI how to:
- Discover available workflows.
- Use the `systematic_skill` tool.
- Follow the "invoke before response" discipline.
- Create git worktrees at `.worktrees/<branch>` under the main repository root with the `git-worktree` skill, unless you or a project instruction name a different location or tool. This rule is left out when `git-worktree` is in `disabled_skills`.

## Code Map

For developers looking to contribute or understand the implementation, here are the key modules:

| Symbol | Role | Location |
|--------|------|----------|
| `SystematicPlugin` | Main plugin factory | `src/index.ts` |
| `createConfigHandler` | Implements the `config` hook logic | `src/lib/config-handler.ts` |
| `createSkillTool` | Implements the `systematic_skill` tool | `src/lib/skill-tool.ts` |
| `getBootstrapContent` | Handles system prompt injection | `src/lib/bootstrap.ts` |
| `findSkillsInDir` | Discovers bundled skills | `src/lib/skills.ts` |
