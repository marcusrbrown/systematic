# Promotion Drafts

This directory contains durable promotional copy for Systematic, organized by channel. Each file is a ready-to-post draft — or as close to ready as a committed artifact can be — subject to the fill step described below.

## Voice Rules

All copy in this directory speaks in Marcus's first-person voice, directly. The tone is blunt and problem-first: state the problem, state what the tool does, stop. No hype, no superlatives, no emoji spam, no "AI-powered" filler. If a sentence wouldn't survive a "so what?" challenge, cut it.

These drafts are committed to public git history. That means they must be **evergreen**: no launch dates, no "today", no time-bound claims, no positioning that will age badly in six months. If the positioning shifts materially, update the file rather than leaving stale copy.

## Count Placeholders

Drafts use `{{SKILLS}}`, `{{AGENTS}}`, `{{COMPONENTS}}`, and `{{VERSION}}` wherever a live count or version number would appear. These are intentional sentinels — a draft with unsubstituted `{{...}}` is obviously unfinished, so stale numbers cannot silently ship.

### Fill Step (run immediately before posting)

The canonical counts live in `docs/src/data/stats.json` (generated by `bun run docs:generate`). Substitute all placeholders in one pass:

```sh
SKILLS=$(jq -r '.skills' docs/src/data/stats.json) \
AGENTS=$(jq -r '.agents' docs/src/data/stats.json) \
COMPONENTS=$(jq -r '.components' docs/src/data/stats.json) \
VERSION=$(jq -r '.version' docs/src/data/stats.json) \
&& for f in docs/promotion/*.md; do
  sed \
    -e "s/{{SKILLS}}/$SKILLS/g" \
    -e "s/{{AGENTS}}/$AGENTS/g" \
    -e "s/{{COMPONENTS}}/$COMPONENTS/g" \
    -e "s/{{VERSION}}/$VERSION/g" \
    "$f"
done
```

Run `bun run docs:generate` first if the repo has new skills or agents since the last build, then run the fill step to produce the final posting text. Do not commit the substituted output — the sentinel form is the canonical source.

## Permanent-Record Caveat

These files are in public git history. Do not include anything that would be embarrassing, misleading, or legally problematic as a permanent record. If a draft becomes stale or the positioning changes, update or remove it — do not leave incorrect claims committed indefinitely.
