**Description (paste into the LinkedIn Projects "Description" field):**

Systematic is an OpenCode plugin I built to add engineering discipline to AI-assisted development. Out of the box, OpenCode is a capable coding agent, but it has no opinion about process — no planning pass, no structured review, no way to capture what you learned before the session ends. Systematic adds that layer without getting in the way.

The plugin bundles {{SKILLS}} workflow skills and {{AGENTS}} specialized subagents. The core loop is brainstorm → plan → work → review. Each phase has a skill that drives it: brainstorming surfaces requirements and tradeoffs before a single line is written; planning produces a structured implementation breakdown; work executes against the plan with quality guardrails; review runs a multi-persona code review before the PR opens. Captured learnings compound across sessions.

The plugin ships with skills for adjacent workflows too — TDD, frontend design, git operations, browser automation, and more. Everything is MIT-licensed, self-contained in the repo, and the plugin runtime sends no telemetry.
